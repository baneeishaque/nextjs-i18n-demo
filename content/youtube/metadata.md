### Description

```text
A production-shaped multilingual demo in Next.js 16 + next-intl: six locales (English,
Hindi, Malayalam, Tamil, Kannada, Arabic), right-to-left support without per-language CSS,
ICU plurals including Arabic's six forms, multilingual SEO, and 66 automated tests.

Code + architecture docs: https://github.com/baneeishaque-ompventure/nextjs-i18n-demo

Chapters:
0:00 One codebase, six languages
0:13 One URL per language
0:27 RTL without forking
0:39 Six plural forms
0:51 Formatting follows the locale
1:04 SEO search engines trust
1:15 66 tests prove it
1:26 Steal the checklist

What the demo proves:
- Locale-prefixed routing with edge detection (cookie → Accept-Language → default)
- Every page statically generated per locale
- RTL via one dir attribute + logical CSS properties, asserted by geometry in E2E
- ICU message catalogs verified against CLDR plural categories
- Canonical URLs, hreflang alternates, and sitemap from a single module
- 45 unit tests (Vitest) + 21 end-to-end tests (Playwright) against a production build

Stack: Next.js 16, next-intl, TypeScript, Tailwind v4, Vitest, Playwright.
License: MIT
```
